# Events Poster Maker

A one-page web app for building the MCGI Hamilton · Tauranga · Rotorua "Upcoming Events" poster.

- Add sections (Current month, Upcoming month, Every week) and their events.
- The poster redraws live at 1920 × 1080 (TV / vMix size) and downloads as a PNG.
- Card colours are automatic: navy for the current month, blue for upcoming months, gold for weekly events, teal for Thanksgiving, red for Blood Donation.
- Multi-day events show a date range and an "N DAYS" tag; any event can have a small uploaded icon.
- Drag the ⋮⋮ handles to reorder events and sections.
- Work in progress and saved posters are kept in your browser. Use **Save backup** to keep a copy as a file.

Everything is in `index.html` — no build step. Hosted with GitHub Pages.
